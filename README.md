# Shahilulla S — Portfolio

A lightweight static portfolio website for GitHub Pages.

## Files
- `index.html` — complete portfolio page
- `style.css` — responsive design system
- `script.js` — theme toggle, mobile navigation, project case-study modals
- `resume.pdf` — replace this with your actual resume PDF

## Publish
Create a public GitHub repository named `shahilulla.github.io`, upload these files, then enable GitHub Pages from Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

GitHub Pages can host static files directly. See the official GitHub Pages documentation:
https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
